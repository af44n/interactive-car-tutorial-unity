# Interactive Car Tutorial

Learning Unity 3D development. Created an interactive 3D tire changing tutorial system in Unity.

## Features

- First person player movement and interaction system
- 8 step guided tire changing tutorial flow
- Pickup and placement mechanics for tools and tires
- Car jacking and wheel hub attachment logic
- UI HUD progress banner and 3D directional arrow indicators

## Controls

- WASD: Move
- Mouse: Look around
- E: Pick up / Place item
- F: Enter / Exit vehicle
- ESC: Toggle settings menu

## Tech Stack

- Unity 6 (URP)
- C#
